
## Math Question Checklist

Use this template before asking or designing a math question.

### 1. Start with the core idea
- What is the main object, pattern, theorem, or problem?
- Can I state it in one sentence?
- What am I actually trying to find, prove, compare, or generate?

### 2. Identify assumptions
- What conditions are given?
- Which assumptions are essential?
- Which assumptions could be removed, weakened, or replaced?

### 3. Test variants
- What happens if I change one parameter?
- What happens in the simplest case?
- What happens in the extreme or boundary case?
- What happens if I scale up, scale down, or take a limit?

### 4. Explore structure
- Can I list small examples?
- Can I find a pattern?
- Can I find a counterexample?
- Is there symmetry, invariance, or conservation?

### 5. Reframe the question
- Can I ask for all solutions instead of one?
- Can I reverse the problem and ask for the inputs that give a chosen output?
- Can I rewrite it in a different branch of math?
- Can I ask for a visual, geometric, algebraic, or combinatorial version?

### 6. Generalize or specialize
- Can I make the statement more general?
- Can I make the statement more specific?
- Does the result still hold in a broader setting?
- What is the narrowest case where it still works?

### 7. Improve the question
- Is the question precise enough?
- Is it interesting enough?
- Is it answerable with the current information?
- Does it invite insight, pattern-finding, or proof?

### 8. Final check
- Is there exactly one thing being asked?
- Are the terms defined clearly?
- Is the problem too easy, too broad, or too constrained?
- Would a different wording make it more creative?
