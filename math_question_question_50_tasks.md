
Here are 50 TO DO items that turn question-asking techniques into concrete actions for creating mathematical questions.

## TO DO list

1. Pick one known theorem, identity, or problem as a seed.
2. Write down every assumption in the seed problem.
3. Negate one assumption and ask what still holds.
4. Remove one condition and test whether the statement survives.
5. Strengthen one condition and see how the answer changes.
6. Replace a specific number with a variable.
7. Replace a variable with a parameter.
8. Ask for the boundary case of the problem.
9. Push the problem to an extreme value.
10. Ask what happens when a quantity becomes zero.
11. Ask what happens when a quantity becomes infinite.
12. Ask what happens when two objects become equal.
13. Ask what happens when two objects become orthogonal, parallel, or disjoint.
14. Ask what happens in the simplest nontrivial case.
15. Ask what happens in the smallest dimension.
16. Ask what happens in the largest dimension you can imagine.
17. Ask whether the result still works for all values or only some.
18. Find a counterexample when a hypothesis is removed.
19. Turn the conclusion into a question.
20. Turn the answer into a question.
21. Reverse the problem: start from a desired answer and ask what inputs produce it.
22. Ask for all solutions, not just one.
23. Ask for the set of all objects satisfying the condition.
24. Ask for an example and a nonexample.
25. Ask whether there are infinitely many examples.
26. Ask whether there are finitely many examples.
27. Ask for a pattern in the first few cases.
28. Compute small cases and look for structure.
29. Compare two neighboring cases.
30. Ask how the problem changes under scaling.
31. Ask how the problem changes under translation, rotation, or permutation.
32. Rewrite the problem in another form.
33. Translate the problem into geometry.
34. Translate the problem into algebra.
35. Translate the problem into combinatorics.
36. Translate the problem into probability.
37. Translate the problem into graph theory.
38. Generalize the problem to a broader class.
39. Specialize the problem to a narrower class.
40. Add a new constraint and ask what changes.
41. Remove a constraint and ask what breaks.
42. Ask for a proof by a different method.
43. Ask for a proof without using a standard theorem.
44. Ask for an intuitive explanation.
45. Ask for a visual or diagrammatic interpretation.
46. Ask for an algorithm to generate examples.
47. Ask for the most elegant or shortest solution.
48. Ask whether the statement is symmetric.
49. Ask whether the statement is invariant under a transformation.
50. Ask what the “right” generalization of the problem should be.
